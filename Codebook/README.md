# Corruption and Political Economy Data Codebook

The Corruption and Political Economy (CorruptPolitEcon) data is a dataset that combines several indicators surrounding corruption, democratic politics, and informal labor 
employment across countries.

The data comes from the V-Dem index (https://www.v-dem.net) the Corruption Perceptions Index (https://www.transparency.org/en/cpi/2024) and the ILO's statistics on the 
informal economy (https://ilostat.ilo.org/topics/informality/)
